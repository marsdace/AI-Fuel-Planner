## 当次结论（暴露的 2 个关键缺陷）

1. **最大心率数据来源错误**：V1 直接取 .FIT 本次运动峰值（175 bpm），真实生理最大心率约 185 bpm，导致心率区间整体偏移、AI 强度评估低估。
2. **补给点缺失 + 负重未建模**：全部补给一次性携带，初始负重 ~2.5kg（约 3.3% 体重），按每 1% 体重 +2~3 bpm 估算，额外增加心率 7-10 bpm。

# Trail Lab · AI Fuel Planner 技术文档 03 —— 补给科学基线

> 面向对象：想理解本程序"为什么这么算"的用户与开发者。
> 上一篇讲了数据层（FIT），这一篇讲**引擎背后的营养学依据**：碳水、液体、钠、咖啡因、蛋白质、肠胃耐受各自的理论基线。这些基线就是 `engine.js` 里各种系数的来源。

> ⚠️ 本程序为**开源研究项目**，以下内容仅供补给算法研究参考，不构成医疗或运动营养建议；工程化系数均标注"待实测校准"。

---

## 一、碳水：按时长分档，主区间 60-90 g/h

碳水该吃多少，看**运动时长和强度**，不是看体重（Jeukendrup 阶梯模型）：

| 运动时长 | 碳水建议 | 糖源 |
|---------|---------|------|
| < 45 分钟 | 无需补给 | - |
| 45-75 分钟 | 极少或仅漱口 | - |
| 1 - 2.5 小时 | 30-60 g/h | 单一碳水 |
| 2.5 - 3 小时 | 60-90 g/h | 多转运体碳水（双糖） |
| > 3 小时 | 90-120 g/h（需肠道训练） | 双糖 |

**为什么 60 g/h 是坎？** 葡萄糖经 SGLT1 转运体吸收，单一糖源氧化上限约 60 g/h；果糖走 GLUT5 通道，葡萄糖 + 果糖双糖组合（约 1:0.8）能突破上限。

**本程序的上限规则**（`engine.js` CHO 模型）：

```
目标速率 = min(档位值, 90, 已验证碳水上限 verified_cho_max)
无实测 → 上限默认 60 + 低置信度
≥ 60 g/h → 强制双糖配比
全局上限 = min(90, verified_cho_max)   # 肠胃约束
```

**已验证碳水上限**：你比赛能吃多少，上限是你平时训练里真实做到过、且肠胃没出问题的量——不是模型或 AI 拍的数。

---

## 二、液体：按个人出汗率，不是固定值

出汗率个体差异 **0.5-4.0 L/h**，固定补液速率不成立。出汗率要自己测：

```
出汗率 =（运动前体重 − 运动后体重 + 摄入液体 − 排尿量）÷ 运动时长
```

**本程序的补液模型**（`engine.js` Fluid 模型）：

```
推荐液体区间 = [0.65 × 汗率, 1.0 × 汗率]
上限：运动中体重不增加
有实测汗率 → 用实测；无 → 按环境 + 体重 + 强度估算
       输出 400-800 mL/h 保守区间 + 低置信度 + "请实测校准"提示
```

补液目标：避免体重下降超 2%；但**不要喝到体重增加**——过量饮水风险高于轻度脱水。

---

## 三、钠：按"浓度 × 饮水量"，不是单一 mg/h

汗液钠浓度个体差异极大（10-100 mEq/L）——同样出汗量，钠流失可以差好几倍，固定剂量必有人不够、有人过量。

```
钠摄入（mg/h）= 饮料钠浓度（mg/L）× 饮水量（L/h）+ 盐丸（mg）+ 含盐食物（mg）
```

**算例**：600 mg/L 电解质水，喝 0.8 L/h → 480 mg/h；喝 1.2 L/h → 720 mg/h。**同一个浓度，钠摄入差很多——单报 mg/h 信息不完整。**

参考区间：ACSM 建议 300-600 mg/h，高温高汗 600-1000 mg/h。

**本程序的钠模型**：输出"浓度 + 实际摄入"双指标；无实测汗液钠时用保守区间；多来源叠加上限 1000 mg/h。

---

## 四、咖啡因：独立建模

```
咖啡因预算 = 体重（kg）× [3, 6] mg
```

- < 4h：可选
- 4-6h：后段使用
- > 6h：分阶段使用（夜间给睡眠警告）
- 不提供能量，是"骗过"大脑的疲劳感知；个体差异大，赛前先小剂量测试

---

## 五、蛋白质：50km 以上才登场

- 脂肪 1g ≈ 9 大卡，是碳水两倍多，低强度阶段供能比例上升
- 连续下坡是离心收缩，会损伤肌肉；赛中少量蛋白能减缓分解、降中枢疲劳
- 赛后 2h 内补蛋白 + 碳水，启动肌肉修复和糖原合成

**本程序**：蛋白质模型 >50km 启用（赛中 5-10 g/h，赛后 2h 内补蛋白 + 碳水）。

---

## 六、肠胃耐受：全局上限

跑步时血液涌向肌肉、肠胃缺血，消化能力大降。上限 = **你自己已验证能吃多少**，不是模型/AI 算的。

**本程序**：全局上限 `min(90, verified_cho_max)`；`verified_cho_max` 无数据默认 60 + low 置信度；F4（90-120）仅当实测 ≥90 且标记"肠道训练/历史验证"时开放。

---

## 七、距离分段：理论普适，落地分档

- **底层理论原则**普适所有单日超马（100km、168km、UTMB 级别）及多日赛
- **落地执行不能一刀切**：≤70km 走"竞技化"（液体 + 胶为主）；100km+ 走"战术化"（真食 / 夜间热流质 / 蛋白频次 / 咖啡因轮换）
- 当前版本以实现 ≤70km / ≤5000m 为主，100km+ 战术化分支仅预留接口
